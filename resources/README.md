## 🎯 主线教材 / 课程

| 优先级 | 资源 | 说明 |

| ⭐ 阶段一 | 《深度学习入门：基于Python的理论与实现》（斋藤康毅，即「鱼书」） | 从感知机到 CNN，纯 numpy 手写，适合入门 |
| ⭐ 阶段二 | 李沐《动手学深度学习》（[d2l.ai](https://zh.d2l.ai/)） | PyTorch 版，配套视频课程，内容全面 |
| ⭐ 阶段三 | Kaggle Learn（[kaggle.com/learn](https://www.kaggle.com/learn)） | 免费微课程：Python、Intro to ML、Intermediate ML、Deep Learning 等 |
| ⭐ 实战 | Kaggle 竞赛 | 目标明年冲铜牌；先完成 Titanic / House Prices 入门赛 |
