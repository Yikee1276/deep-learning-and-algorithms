# 深度学习 × 算法 · 学习仓库

> 目标：从入门到实战——跟着「鱼书」与《动手学深度学习》打基础，明年参加 **Kaggle** 并冲击铜牌。
> 本仓库记录学习笔记、代码与项目，每周提交、每月复盘，用 git 历史见证成长。

## 📌 关于这个仓库

- **起点**：Python / C++ 编程基础；学过计组、高数、线性代数，但忘得差不多了 → 数学类内容**随用随学**（遇到卡点再补）
- **节奏**：每周 5~7 次学习，每次 1~2 小时
- **原则**：先理解再编码，每周有产出并提交；计划随情况调整
- **目标**：明年参加 Kaggle，拿下铜牌 🥉

## 📁 目录结构


## 🗺️ 学习路径

### 阶段一 · 鱼书入门（《深度学习入门：基于Python的理论与实现》）

- 感知机 → 神经网络（前向传播）→ 反向传播 → 学习技巧 → 卷积神经网络
- **重点**：不依赖框架，用 numpy 手写一遍，理解每个公式怎么在代码里落地
- **产出**：手写 MLP / CNN 代码 + 每章推导笔记

### 阶段二 · 李沐《动手学深度学习》（d2l）

- PyTorch / 张量与自动求导 → 线性回归 → 多层感知机 → 卷积网络 →（选学）循环网络 / 注意力 / Transformer
- **重点**：从手写过渡到框架，学会训练循环、调参、GPU 使用
- **产出**：d2l 代码复现 + 训练记录

### 阶段三 · Kaggle 免费课程 + 实战

- Kaggle Learn：Python → Intro to Machine Learning → Intermediate ML → Deep Learning → Pandas / Feature Engineering
- **重点**：数据探索、特征工程、验证集划分、模型提交
- **产出**：入门赛（Titanic / House Prices）完成 baseline，沉淀 notebook 技巧
- **明年**：正式参赛，目标铜牌 🥉

> 学习路径是滚动计划：每个阶段结束做一次复盘，视情况调整顺序与时长。

## 📝 每周工作流

1. 每周日写 **weekly-log/YYYY-Wxx.md**：本周学了啥、踩了什么坑、下周计划
2. 笔记写进 **notes/**，代码写进 **code/**，项目放 **projects/**
3. 提交信息用统一格式：`type(scope): summary`
   - `docs(dl): 鱼书 4-2 误差反向传播笔记`
   - `feat(dl): 手写两层感知机`
   - `feat(kaggle): Titanic baseline 提交`
4. 每月最后一周做一次复盘，更新进度看板

## 🧭 随用随学说明

- 高数 / 线代 / 计组等忘了的内容**不设专门补课阶段**，遇到用到的概念再查、再补
- 查漏补缺的笔记放 `notes/math-*.md`、`notes/cs-*.md`
- 优先级：鱼书与 d2l 主线 > Kaggle 实践 > 补课
